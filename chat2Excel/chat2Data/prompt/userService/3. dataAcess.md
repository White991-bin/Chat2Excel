**任务**：帮我完成用户子服务中数据操作封装，主要对odb生成代码进行封装，以及redis++操作缓存进行封装。

**要求如下**
1. 用户信息表
- odb对UserEntity类编译生成代码在chat2data-tech/chat2Data/data/odb目录下
- 定义UserData类，包含在userService命名空间中
- 头文件userData.h，源文件userData.cc，放置在chat2data-tech/chat2Data/data目录下
- 类中包含MySQL句柄，用以操作MySQL中用户信息表；类中包含Redis句柄，用以操作Redis中用户信息
- mysql句柄使用odb生成的代码定义，redis句柄使用bite_scoffold中redis的工厂类创建，位置：libSource/cpp-microservice-scaffold/source/redis.h
- UserData类中涉及MySQL操作：
    - 保存用户信息
    - 通过用户Id获取用户信息
    - 通过用户昵称获取用户信息
    - 通过用户邮箱获取用户信息
    - 检测用户昵称是否存在
    - 检测用户邮箱是否存在
- UserData类中涉及Redis操作：
    - 更新用户信息到缓存
    - 通过用户Id从缓存中获取用户信息
    - 通过用户昵称从缓存中获取用户信息
    - 通过用户邮箱从缓存中获取用户信息
- UserData的缓存策略，使用Cache-Aside(旁路缓存)策略：
    过期时间：1小时
    缓存策略：
    - 写策略：写DB成功后，删除Redis。
    - 读策略：先查redis，未命中再查DB，查到后回填Redis。
    - 删除/失效策略：依赖TTL自然过期(因为chat2Data不支持用户注销，个人信息缓存自然过期即可)。
    缓存类型：hash
    key：user:userId
    key：user:nickname:username
    key：user:email:userEmail
    value：
    - 用户id
    - 用户昵称
    - 用户密码
    - 用户邮箱
    - 用户状态
2. 会话表
- odb对SessionEntity类编译生成代码在chat2data-tech/chat2Data/data/odb目录下
- 定义SessionData类，包含在userService命名空间中
- 头文件sessionData.h，源文件sessionData.cc，放置在chat2data-tech/chat2Data/data目录下
- 类中包含MySQL句柄，用以操作MySQL中会话表；类中包含Redis句柄，用以操作Redis中会话信息
- mysql和redis句柄创建方式与UserData类相同
- SessionData类中涉及MySQL操作：
    - 保存会话信息
    - 通过会话Id获取会话信息
    - 删除指定会话信息
- SessionData类中涉及Redis操作：
    - 更新会话信息到缓存
    - 通过会话Id从缓存中获取会话信息
    - 通过会话Id从缓存中删除指定会话
- SessionData的缓存策略，使用Cache-Aside(旁路缓存)策略：
    过期时间：3天
    缓存策略：
    - 写策略：先写DB，删除Redis
    - 读策略：先查redis，未命中再查DB，查到后回填Redis(同样设置TTL为3天)。
    - 删除策略：先删DB再删Redis，或者TTL到期后自动删除
    缓存类型：hash
    key：session:sessionId
    value：
    - 会话Id
    - 用户Id

3. 验证码缓存
- 定义VerifyCodeData类，包含在userService命名空间中
- 头文件verifyCodeData.h，源文件verifyCodeData.cc，放置在chat2data-tech/chat2Data/data目录下
- 类中包含Redis句柄，用以操作Redis中验证码信息
- redis句柄创建方式与UserData类相同
- VerifyCodeData类中涉及Redis操作：
    - 保存验证码信息到缓存
    - 通过验证码Id从缓存中获取验证码信息
    - 通过验证码Id从缓存中删除指定验证码
- VerifyCodeData的缓存策略，使用Cache-Aside(旁路缓存)策略：
    过期时间：5min
    缓存策略：
    - 读策略：读Redis，用后即删(并没有物理删除，只是将其标记为不可用，物理删除依靠TTL)
    - 删除策略：用后即删 或 TTL到期后自动删除
    缓存类型：hash
    key：verifyCode:codeId
    value：
    - 验证码Id
    - 验证码
    - 用户邮箱
    - 验证码创建时间
