**系统身份**：你是一个资深的C++后端开发工程师，熟悉odb数据库映射类的编写，以及odb工具使用。

**任务**：帮我给用户子服务编写odb数据库表映射类，完成用户表和会话表的C++类映射，并完成映射类的编译。

**用户表设计**
| 字段 | 类型 | 约束 | 空值 | 备注 |
| --- | --- | --- | --- | --- |
| id | BIGINT UNSIGNED | PRI | NOT NULL | 主键 |
| userId | varchar(32) | URI | NOT NULL | 必须唯一 |
| nickname | varchar(32) | URI | NOT NULL | 必须唯一 |
| email | varchar(255) | URI | NOT NULL | 必须唯一 |
| password | TEXT |  | NOT NULL | 存储加密后结果 |
| status | TINYINT |  | NOT NULL | 0：未登录，1：已登录 |

**注意事项**
- 密码必须存储加密后结果，不能存储明文密码。
- 系统支持用户昵称登录，因此用户昵称必须唯一。
- 系统支持用户邮箱登录，因此用户邮箱必须唯一。
- 创建用户表的SQL语句以及CURD操作将来由odb负责生成。

**会话表设计**
| 字段 | 类型 | 约束 | 空值 | 备注 |
| --- | --- | --- | --- | --- |
| id | BIGINT UNSIGNED | PRI | NOT NULL | 主键 |
| sessionId | varchar(32) | URI | NOT NULL | 必须唯一 |
| userId | varchar(32) | | NOT NULL | |
**注意事项**
- 会话表中会话Id必须唯一
- 会话表中用户Id可以重复，因为chat2Data支持多设备登录相同账号，不同设备登录后对应不同的会话
- 创建会话表的SQL语句以及CURD操作将来由odb负责生成。

要求如下：
1. 编写odb数据库表映射类。
    - 编写用户表的odb映射类UserEntity，表名tbl_user，严格按照用户表设计中的字段进行映射。
    - 编写会话表的odb映射类SessionEntity，表名tbl_session，严格按照会话表设计中的字段进行映射。
    - UserEntity头文件名称userEntity.h，SessionEntity头文件名称sessionEntity.h。
    - 头文件存放路径：chat2data-tech/chat2Data/data/

2. 编写odb映射类编译的CMakeLists.txt文件，完成UserEntity和SessionEntity类的编译，要求：
    - CMakeLists.txt文件放置在chat2data-tech/chat2Data/data目录下
    - odb编译后生成的代码文件放置在chat2data-tech/chat2Data/data/odb目录下
    - odb编译后生成的.sql文件放置在chat2data-tech/chat2Data/data/sql目录下
    
请求仔细阅读用户表和会话表的表设计，以及映射类的实现要求，完成用户子服务中用户表和会话表的C++类映射，并完整编译。
