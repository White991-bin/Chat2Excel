## excel解析子服务实现

### 1. excel解析子服务介绍

excel解析子服务属于内部服务，不和网关进行交互，仅为文件子服务提供excel文件解析服务，功能包含：解析excel中所有worksheet 以及 各个worksheet中的数据。
在用户上传excel文件后，前后端的数据流向如下：
- 用户在前端页面上上传excel文件
- 网关收到上传excel文件请求后，进行鉴权以及协议转换后，将上传excel文件请求路由给文件子服务
- 文件子服务将excel文件保存到本地，然后调用excel解析子服务对excel文件进行解析
- excel解析子服务解析出该excel文件中的所有worksheet 以及 各个worksheet中的数据，并返回到文件子服务中
- 文件子服务获取到excel子服务解析的各个worksheet的数据后，会将worksheet表数据存储到数据库
- 文件子服务将文件上传结果返回给网关
- 网关将上传文件结果返回给前端
- 前端进行页面渲染

### 2. 接口定义

excel解析子服务总共涉及到2个RPC接口，分别是：
- 解析execl文件的所有worksheet
- 解析excel文件中指定worksheet的表结构以及表数据

具体的RPC接口定义如下：
```proto

syntax = "proto3";
package chat2Data.excelParseService;
option cc_generic_services = true;

//////////////////////// 获取工作表列表 ////////////////////////
message GetWorksheetsRequest {
  string request_id = 1;           // 请求ID
  string file_path = 2;            // 文件路径
}

message GetWorksheetsResponse {
  string request_id = 1;           // 请求ID
  int32 error_code = 2;            // 错误码
  string error_msg = 3;            // 错误信息
  repeated string worksheets = 4;  // 工作表列表
}

//////////////////////// 解析 Excel 文件 ////////////////////////
message ParseExcelRequest {
  string request_id = 1;           // 请求ID
  string file_path = 2;            // 文件路径
  repeated string worksheets = 3;  // 工作表列表
}

//////////////////////// 解析 Excel 文件 ////////////////////////
message ProtoColumnInfo {
  string name = 1;                  // 列名
  string type = 2;  // TEXT, BIGINT, DOUBLE, BOOLEAN, DATE
}

message ProtoCellData {
  string value = 1;                 // 单元格值
  string type = 2;  // Empty, Integer, Float, Boolean, String
}

message RowData {
  repeated ProtoCellData cells = 1;  // 单元格数据
}

message WorksheetData {
  string name = 1;                       // 工作表名
  repeated ProtoColumnInfo columns = 2;  // 列信息
  repeated RowData rows = 3;             // 行数据
  int32 total_rows = 4;                  // 总行数
  int32 total_cols = 5;                  // 总列数
}

message ParseExcelResponse {
  string request_id = 1;                 // 请求ID
  int32 error_code = 2;                  // 错误码
  string error_msg = 3;                  // 错误信息
  repeated WorksheetData worksheets = 4; // 工作表数据
}

// Excel解析RPC接口定义
service ExcelParserService {
  // 获取工作表列表
  rpc GetWorksheets(GetWorksheetsRequest) returns (GetWorksheetsResponse);
  // 解析 Excel 文件，返回结构化数据
  rpc ParseExcel(ParseExcelRequest) returns (ParseExcelResponse);
}

```
### 3. excel解析器

excel解析器ExcelParser基于OpenXLSX库实现，向业务层提供：
1. 解析excel文件所有worksheet的worksheet名称
2. 解析指定worksheet的表数据
可参考chat2data-tech/chat2ExcelEasy/source/execlParser.h 和 execlParser.cc。该参考示例中关于worksheet数据解析比较简单，没有单独解析表头信息、列类型信息、表数据，而是直接读取worksheet的单元格数据返回了。但excel解析子服务中的解析器需要单独解析表头信息、列类型信息、表数据，文件子服务将来需要用这些信息将excel的worksheet数据以数据库表的形式存储到数据库中。

#### 3.1 表头信息

即表的第一行，每列的第一个单元格内容作为列名。如果列名为空，使用column_列号（例如：column_1）作为列名。
注意：解析出列名后，需要验证列名是否有效：
- 列名中只能包含大小写字母、数字、下划线，以及中文，非法字符使用_替换；
- 如果列名首字符为数字时，在列名前加前缀col_列名。

#### 3.2 列类型信息

采样worksheet的前100行数据，将每列的100个单元格类型出现次数最多的类型作为该列的类型。
在逐个检测某列的各个单元格类型时，要考虑：
- 如果单元格为空或N/A时，不统计该单元格
- 如果单元格类型不是整型、浮点型、布尔型时，需根据该列的值检测该单元格是否为数值、bool值以及日期
- 如果是数值，作为浮点型统计。检测时需要将单元格数值的前后空白字符去掉，如果转成浮点数后，原字符串删除浮点数结果，剩余内容除空白字符外不包含其他字符，说明该单元格值就是数值类型。
- 如果是布尔值，作为布尔型统计。检测时需要考虑布尔型的各种可能性。比如真：true、1、t、yes、y，假：false、0、f、no、n等。
- 如果是日期，作为日期类型统计。检测时需要考虑日期的各种可能性。比如yyyy-MM-DD、YYYY/MM/DD、MM-DD-YYYY、MM/DD/YYYY、YYYY.MM.DD、MM.DD.YYYY、YYYY-MM-DD HH:MM:SS等。
- 如果以上情况都不符合，作为字符串类型统计。
- 将某列的100个单元格类型统计完成之后，将类型出现次数最多的类型作为该列的类型。

#### 3.3 表数据

解析出worksheet中除表头行外的所有数据行，返回结果中每个单元格需要包含数值以及单元格类型。
注意，在解析每个单元格时，如果：
- 单元格为整形时，将其转为int64类型后再转为字符串
- 单元格为浮点型时，将其转为double类型后再转为字符串
- 单元格布尔型时，根据布尔值结果将其转为"0"或"1"
- 其余类型统一转为字符串类型

注意：实现时尽量避免大段代码，尽量将每个功能封装成独立的函数。

### 4. 业务层实现

excel解析业务层主要由ExcelParserBusiness类实现，是对ExcelParser的封装，主要包含：
1. excel解析器实例指针
2. 解析excel文件所有worksheet的worksheet名称
3. 解析指定worksheet的表数据，组织成rpc接口需要的WorksheetData的结构化数据

### 5. RPC接口实现

excel解析RPC接口实现主要由ExcelParserServiceImpl类实现。
rpc接口会通过proto工具C++服务基类，保存在/home/dev/workspace/chat2data-tech/chat2data-tech/chat2Data/proto/protoCode目录中，ExcelParserServiceImpl类继承proto生成的ExcelParserService类，并通过ExcelParserBusiness类实例实现解析excel的worksheet 以及 解析worksheet表数据的虚函数。

### 6. RPC服务器搭建
RPC服务器搭建由ExcelParserServer类实现，该类内部包含：
- 服务注册对象指针：用于注册服务到注册中心。
- brpc服务器对象指针：用于启动RPC服务器。
- rpc接口类对象指针：用于实现RPC接口。

RPC服务器对象创建、注册中心对象创建、excel业务层以及接口层实例创建，由ExcelParserServerBuilder类完成。
ExcelParserServerBuilder类通过建造者模式，完成RPC服务器端口、注册中心结构初始化，最后通过build构造好各个对象并返回RPC服务器对象。
