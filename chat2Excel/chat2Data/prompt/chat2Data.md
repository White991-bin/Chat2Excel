## chat2Data项目介绍

### 1. 项目简介
chat2Data项目是一款基于C++17实现的微服务项目，该项目将LLM与数据分析项结合，让用户能通过自然语言操作Excel文件以及数据库，让没有技术背景的人也能高效处理复杂、海量数据。

### 2. 项目架构

chat2Data项目采用微服务架构，总共拆分为7个子服务：
- **网关子服务**：前端访问唯一入口，接收浏览器请求，并进行鉴权、协议转换、负载均衡，将请求分发给其他子服务。
- **用户子服务**：提供用户信息的获取、修改、插入、删除等各项操作
- **文件子服务**：提供文件上传、下载、删除、文件列表获取、文件预览、文件存储管理等操作
- **Excel解析子服务**：负责Excel文件解析
- **存储子服务**：负责用户信息、聊天信息、Excel数据等存储管理
- **AI子服务**：负责和模型交互，以及聊天会话、聊天消息管理
- **通知子服务**：负责验证码获取、AI结果发送邮件等操作

### 3. 各子服务涉及的功能

#### 3.1 网关子服务
通过cpp-httplib库搭建网关服务器(HTTP服务器)，实现30个HTTP接口处理浏览器请求；
通过bite_scoffold提供的服务器监控模块实现服务发现；
通过bite_scoffold提供RPC模块实现负载均衡以及RPC调用。

#### 3.2 用户子服务
提供用户信息的获取、修改、插入、删除等各项操作。设计的业务功能如下：
- 检测用户昵称是否唯一
- 检测邮箱是否唯一
- 用户注册
- 昵称密码登录
- 邮箱登录
- 会话登录
- 获取验证码
- 退出登录
- 获取个人信息

#### 3.3 文件子服务
提供文件上传、下载、删除、文件列表获取、文件预览、文件存储管理等操作。设计的业务功能如下：
- 上传文件信息
- 获取文件信息
- 上传文件
- 下载文件
- 删除文件
- 预览Excel表格
- 获取文件列表信息
- 关联文件和聊天会话
- 上传SQLite文件

#### 3.4 Excel解析子服务
负责Excel文件解析，将解析后的worksheet表结构 以及 表数据返回给上层文件子服务，文件子服务会将其存入数据库。
在子服务属于内部服务，不和网关进行交互，专门为文件子服务服务。设计的业务功能如下：
- 解析Excel文件所有worksheet
- 提取Excel文件中每个worksheet的表结构和数据

#### 3.5 存储子服务
负责用户信息、聊天信息、Excel数据等存储管理。
设计的业务功能如下：
- 建立数据库连接
- 关闭数据库连接
- 获取数据库表列表
- 获取表数据
- 获取连接状态

#### 3.6 AI子服务
负责和模型交互，以及聊天会话、聊天消息管理。
设计的业务功能如下：
- 获取支持模型列表
- 新建会话
- 给模型发送消息
- 获取会话列表
- 获取历史会话
- 删除会话

#### 3.7 通知子服务
负责验证码获取、AI结果发送邮件等操作。该子服务不与网关通信，专门用户子服务提供发送验证码，以及为AI子服务提供发送邮件功能。
设计的业务功能如下：
- 发送验证码
- 发送AI结果邮件

### 4. 数据流向
用户在前端页面中，可以选择智能Excel助手页面，通过自然语言方式操作Excel文件；通过选择智能DB助手页面，通过自然语言方式操作数据库。目前支持：MySQL 和 SQLite两种数据库。

#### 4.1 智能Excel助手数据流向
用户通过自然语言操作Excel时，完整的流程如下：
    1. 用户上传Excel
    2. 网关将请求转发给文件子服务
    3. 文件子服务调用Excel子服务进行文件解析，解析出所有worksheet以及表结构和数据
    4. 文件子服务调用存储子服务将数据存入数据库
    5. 文件子服务将文件存入fastdfs存储系统
    6. 文件子服务处理上传文件完成，将结果返回给网关
    7. 网关将上传文件响应返回给浏览器
    8. 用户选择模型，创建聊天会话
    9. 用户提问
    10. 网关将请求转发给AI子服务
    11. AI子服务调用数据库子服务获取表结构和采样数据
    12. AI子服务将表结构+采样数据+用户问题+提示词模版构建完整提示词
    13. 将完整提示词发送给大模型
    14. 大模型生成相应SQL
    15. AI子服务调用存储子服务执行SQL语句
    16. AI子服务将SQL执行结果发送给大模型
    17. 大模型生成总结+可视化数据
    18. AI子服务将结果流式返回给网关
    19. 网关将结果返回给浏览器
    20. 浏览器进行最终结果渲染

#### 4.2 智能DB助手数据流向
用户通过自然语言操作Excel时，假设操作MySQL数据库，完整的流程如下：
    1. 用户上传SQLite文件或MySQL数据库连接信息
    2. 发送连接数据库请求
    3. 网关将连接数据库请求转给存储子服务
    4. 存储子服务根据数据库类型连接对应数据库
    5. 返回数据库中所有表列表给网关
    6. 网关将数据库表列表返回给浏览器渲染
    7. 浏览器发送获取指定表表数据请求
    8. 网关将请求转发给存储子服务
    9. 存储子服务根据表名获取表数据
    10. 存储子服务将表数据返回给网关
    11. 网关将表数据返回给浏览器渲染
    12. 用户提问
    13. 网关将请求转发给AI子服务
    14. AI子服务调用数据库子服务获取表结构和采样数据
    15. AI子服务将表结构+采样数据+用户问题+提示词模版构建完整提示词
    16. 将完整提示词发送给大模型
    17. 大模型生成相应SQL
    18. AI子服务调用存储子服务执行SQL语句
    19. AI子服务将SQL执行结果发送给大模型
    20. 大模型生成总结+可视化数据
    21. AI子服务将结果流式返回给网关
    22. 网关将结果返回给浏览器
    23. 浏览器进行最终结果渲染

### 5. 技术选项
| 中间件/第三方框架| 描述 |
| --- | --- |
|ChatSDK|和模型交互SDK|
|bite_scaffold|常用开发库或组件的二次封装，包括BRPC、fastDFS、ETCD、ElasticSearch、AMQP-CPP中间件等，也包含了对spdlog、protobuf、json、gtest等使用等|
|OpenXLSX|用于解析Excel文件|
|Etcd|搭建注册中心|
|MySQL|持久化数据|
|Redis|系统缓存|
|ODB|构建odb映射类，操作数据库更简单|
|brpc|工业级RPC框架，子服务之间通信|
|fastDFS|实现文件上传、下载，存储|
|Jsoncpp|用于序列化&反序列化|
|protobuf|定义各个子服务的RPC接口|
|gflags|命令行参数的声明、定义和解析|
|gtest|跨平台的C++单元测试框架|
|spdlog |高性能、超快速、零配置的 C++ 日志库|
|libcurl|高性能，高可用的多协议网络通信客户端库|
|redis++|C++实现的redis|
|QQ/163邮件推送|用于验证码获取，以及可视化结果邮件通知|
|apifox|Apifox 是一款 API 设计、开发、测试一体化协作平台|
