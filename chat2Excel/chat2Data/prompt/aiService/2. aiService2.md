### 1. 发送消息流程

#### 1.1 聊天场景分类

AI子服务支持三种聊天场景：
- **普通对话场景**：前端发送消息，AI子服务收到后直接将消息发送给模型，模型响应结果直接返回前端进行渲染。
- **智能Excel场景**：
    1. 收集Excel文件元数据：① 通过文件子服务获取worksheet数据库表名列表 ② 通过数据库子服务获取各个worksheet对应数据库表的表结构和5条采样数据。
    2. 构建分析提示词：替换提示词模板中的：数据库类型、表结构、表名、采样数据、用户消息、可视化数据类型等字段。
    3. 利用ChatSDK给模型发送消息，累积模型响应并实时推送给前端。
    4. 从模型响应中提取SQL语句。模型响应中SQL语句被<SQL_START>和<SQL_END>包裹。
    5. 规范化SQL：移除注释和空白、验证是否为支持的SQL、验证是否包含危险关键字
    6. 通过数据库子服务执行SQL并获取执行结果
    7. 生成总结提示词：替换提示词模板中的：用户消息 以及 SQL执行结果
    8. 利用ChatSDK给模型发送消息，累积模型响应并实时推送给前端
    9. 组织可视化数据的JSON格式并返回给前端
    10. 保存聊天消息到ChatSDK内部消息表

- **智能DB场景**：流程与Excel场景基本一致，区别在于第一步是通过请求参数解析获取数据库表名，而非通过文件子服务。

#### 1.2 发送消息RPC接口

```proto

//////////////////////// 发送消息(流式响应) ////////////////////////
enum DataType {
  EXCEL = 0; // Excel场景
  MYSQL = 1; // MySQL场景
  SQLITE = 2; // SQLite场景
}

message SendMessageRequest {
    string request_id = 1;          // 请求ID
    string user_id = 2;             // 用户ID
    string chat_session_id = 3;     // AI聊天会话ID
    string chat_type = 4;           // 聊天类型：excel/database/plain
    string message = 5;             // 用户消息内容
    string file_id = 6;             // 文件ID(Excel场景)
    DataType db_type = 7;           // 数据类型(数据库场景)
    string db_connect_id = 8;       // 数据库连接ID(数据库场景)
    string table_name = 9;          // 表名, 多个表名之间由逗号分隔(数据库场景)
}
/*
 * session_type: 会话类型：excel或database/plain
 * - excel: Excel场景, file_id字段不为空
 * - database: 数据库场景, db_connect_id字段不为空，db_type字段代表了具体的数据库类型, table_name字段表示要操作的数据库表
 * - plain: 普通场景
 */

message SendMessageResult {
    bool done = 1;                     // 是否完成
    string content = 2;                // 消息片段
}

message SendMessageResponse {
    string request_id = 1;             // 请求ID
    int32 error_code = 2;              // 错误码
    string error_msg = 3;              // 错误描述符
    SendMessageResult result = 4;      // 消息结果
}

service AIService {
    // ...
    // 发送消息(流式响应)
    rpc SendMessage(SendMessageRequest) returns (stream SendMessageResponse);
}

```

### 2. 提示词模版

在智能Excel和智能DB聊天场景中，当用户发送消息，比如：帮我统计各个部门员工薪资占比
后端需要给模型发送两次消息：
1. **分析阶段**：发送分析提示词，让模型生成关于用户问题的分析思路以及SQL语句。
2. **总结阶段**：发送总结提示词，让模型根据SQL语句执行结果，生成关于用户问题的总结以及可视化显示数据格式。

如果用户想将和模型聊天的结果发送到邮箱，只要在问题中携带类似发送邮件字样，模型收到后，会通过toolcall方式调用发送邮件函数，将结果发送到用户邮箱。
因此，需要提前定义好分析、总结、发送邮件的提示词模版。
分析提示词、总结提示词、发送邮件提示词都是通用的，提示词内部预留了占位符，在发送消息时，需要根据实际的场景以及用户问题，替换占位符，构建适合当前场景的实际提示词。
提示词模板内容：/home/dev/workspace/chat2data-tech/chat2data-tech/chat2Data/svc_aiService/prompt.md

提示词模板在PromptTemplate类中实现，该类包含：
成员变量：
- 提示词模板
- 占位符和实际值的映射关系

成员方法：
- 使用提示词构建提示词模板对象
- 设置占位符和实际值的映射关系
- 获取实际提示词。该方法内部需要将提示词模板中的占位符替换为实际的值。

分析提示词中的占位符：
{DataBase} ： 数据库类型
{table_schema} ： 数据库表结构
{table_name} ： 数据库表名
{data_example} ： 数据库表采样数据
{user_input} ： 用户消息内容
{display_type} ： 可视化显示类型，可选值为"Table,BarChart,LineChart,PieChart,AreaChart,ColumnChart,DonutChart,ScatterChart,NumberDisplay"

总结提示词中的占位符：
{user_input} ： 用户消息内容
{sql_result} ： SQL语句执行结果

邮件内容生成提示词：
{user_input} ： 分析阶段生成的标题
{email_param} ： 邮件参数，json字符串，包含：
    {
      "question" : "用户原始问题摘要，即分析阶段生成的标题", 
      "analysis" : "分析阶段生成的分析内容",
      "summary" : "总结阶段生成的总结内容",
    }

### 3. 发送消息实现

发送消息模块在AIMessageHandler类中实现，根据1中发送消息流程，需要实现以下功能。

#### 3.1 数据库表获取
- **Excel场景**：通过文件子服务，根据file_id获取Excel文件worksheet数据库表名列表
- **数据库场景**：从传入的请求参数中获取实际要操作的数据库表名列表

#### 3.2 提示词构建

发送消息模块总共需要构建三段提示：
- 构建分析提示词
- 构建总结提示词
- 构建发送邮件提示词

这三个方法在实现时，都需要创建提示词模版，建立占位符和实际值映射关系，获取并返回替换之后的实际提示词。

#### 3.3 普通消息发送

如果请求参数**session_type**为"plain"，说明是普通消息场景，直接使用AIMessageHandler提供的发送普通消息方法，完成普通消息发送。
注意，模型响应完成之后，需要更新聊天会话表中的：
- 会话最近活跃时间
- 消息总数。消息总数增加2条，分别是用户消息和模型响应消息。

#### 3.4 发送邮件

在分析阶段的回复中，如果模型认为用户是想发送邮件，会回复<EMAIL_START>sendEmail<EMAIL_END>以调用发送邮件工具函数。因此，AIMessageHandler中提供方法：
- 检测模型回复是否为发送邮件请求
- 发送邮件
    1. 通过用户子服务，获取用户邮箱
    2. 通过ChatSDK，获取最近两条assistant消息(分析消息和总结消息)
    3. 从分析消息中提取标题和分析内容，从总结消息中提取总结内容，构建邮件参数json对象，并构建发送邮件提示词
    ```json
    {
        "question": "用户问题标题",
        "analysis": "分析过程文本",
        "summary": "总结内容",
    }
    ```
    4. 将提示词发送模型，让模型生成邮件内容。邮件内容json格式：
    ```json
      {
        "subject": "邮件主题",
        "content": "邮件内容，html格式字符串"
      }
    ```
    5. 从模型回复中提取邮件主题和邮件内容
    6. 通过邮件通知子服务，发送邮件
    7. 给前端发送消息<EMAIL_START>邮件发送成功，请注意查收<EMAIL_END>

注意，在发送消息过程中，如果遇到异常情况，需要给前端发送错误描述，比如：<EMAIL_START>邮件发送失败：邮件发送失败具体原因<EMAIL_END>

#### 3.5 发送消息RPC接口

AIMessageHandler提供发送消息方法，发送消息流程如下：
1. 根据**session_type**判断消息场景
    - "plain"：直接发送普通消息并返回。
    - "excel"：获取Excel场景下的数据库表名。
    - "database"：获取数据库场景下的数据库表名。

2. 构建分析提示词
3. 给模型发送消息，分析用户问题，生成SQL语句
4. 检测模型回复是否为发送邮件工具函数，如果是直接调用发送邮件方法并返回
5. 从模型回复中提取SQL语句。其余标签数据后端不关心，直接发送给前端，后端只提取包含在<SQL_START>xxx<SQL_END>之间的SQL语句。
6. 规范SQL语句
7. 执行SQL语句，并获取SQL执行结果。注意执行SQL时，智能Excel场景使用excel_default默认数据库连接，数据库场景请求参数中携带了专门的数据库连接。
8. 构建总结提示词
9. 给模型发送消息，让模型生成总结内容
10. 构建并发送最终响应给前端。根据sql执行结果，填充json结构并返回前端。
    ```json
        {
            "summary": "总结阶段生成的总结内容",
            "displayType": "总结节点生成的可视化显示类型",
            "data": {     // data为sql执行结果
                "columns": ["列1", "列2"],    // 第一张表的列
                "rows": [["值1", "值2"]],     // 第一张表的行
                "tables": [                   // 所有表数据（完整保留）
                    {"columns": [...], "rows": [...]},
                    {"columns": [...], "rows": [...]},
                    {"columns": [...], "rows": [...]}
                ]
            }
        }
    ```

### 4. 业务层AIBusiness完善

AIBusiness::sendMessage方法为接口层提供发送消息支持，但实际发送消息逻辑由AIMessageHandler类实现。即AIBusiness::sendMessage方法使用AIMessageHandler::sendMessage方法，完成发送消息的完整流程。具体操作如下：
- 开启独立线程，由该线程负责消息发送
- 使用brpc::ProgressiveAttachment类，实现流式传输和模型交互
- 线程处理函数中，定义writeChunk回调，用于将模型回复分块推送给客户端，块数据以SSE格式组织
- 使用AIMessageHandler类，完成发送消息的完整流程

注意：模型回复是流式的，该过程可能需要数秒甚至更长的时间，为了避免RPC调用长时间阻塞，发送流式消息在单独线程中进行

### 5. 接口层AIServiceImpl完善

#### 5.1 技术选型
前端和网关之间是通过HTTP协议交互的，发送消息请求的响应中，网关需要以流式方式将AI子服务的流式响应实时推送给前端网页渲染。
ChatSDK内部是通过HTTP+SSE实现流式传输和模型交互，而brpc框架支持RPC、HTTP等多种协议，即brpc框架会自动处理HTTP协议，并路由到对应的RPC方法，因此网关通过HTTP客户端和AI子服务的交互，并将AI子服务的流式响应，通过HTTP+SSE协议实时推送给客户端。这样可以参考ChatSDK内部实现流式传输的示例，降低网关实现难度。

#### 5.2 实现流程
AIServiceImpl::SendMessage实现流程：
1. 解析请求参数
2. 验证参数合法性
3. 校验当前聊天会话是否属于当前用户
4. 设置HTTP响应头，开启流式传输，将RPC响应返回给客户端，但不断开连接，目的是让客户端知道已经和服务器建立连接
5. 通过AIBusiness内部的AIBusiness::sendMessage实现
